6. In urls.py of project: 
    from django.contrib import admin
    from django.urls import path, include

    urlpatterns = [
        path('admin/', admin.site.urls),
        path('app/', include("app.urls"))   # Here we are creating a path 127.0.0.1:8000/app/ and next path is configured in app/urls.py file. 
    ]

7. Create a urls.py in application created: 
    from . import views
    from django.urls import path

    urlpatterns = [
        path('app1', views.index),   # 127.0.0.1:8000/app/app1
    ]

8. Now run the server: python manage.py runserver and go to website: 127.0.0.1:8000/app/app1
