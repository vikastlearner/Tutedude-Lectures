Web Scrapping: This help to read the content of web page.
Want to retrive data then  Encode (string uni code to byte) and Decode (vice versa) it.

Example:
1. Install the library: pip install urllib3
2. create a file "web.py"
    import urllib.request, urllib.parse, urllib.error # import library to encode and decode

    url = urllib.request.urlopen('http://127.0.0.1:8000/app/app') # to open a link
    for line in url:
        print(line.decode().strip())
3. Run the server and run the above python file.
4. To import the other details (seen in network section of inspection), install "pip install requests"

10. To filter the data in webpage:
    - Need to import two package - bs4 and lxml.
    - Create a new file and add following line:
        import requests
    from bs4 import BeautifulSoup

    def Extract(url):
        headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120 Safari/537.36"
        } # header is used because wiki pedia was considering it as bot with "User-Agent: python-requests/2.x"

        response = requests.get(url=url, headers = headers).content
        # print(response)
        soup = BeautifulSoup(response, 'lxml') # second one is parser - html, lxml
        tag = soup.find("div", {"id": "mp-right"}) # name of the tag

        # h = tag.find("h2", {"id":"mp-itn-h2"})
        h = tag.find_all("h2") # prints all h2 data under "div (tag)"
        # h = tag.find("h2", {"id":"mp-itn-h2"}).find(...) # prints selected find data inside the h2.
        # print(h)
        content = [span.text for span in h]
        print(content) # prints only the header.

    Extract(url = 'https://en.wikipedia.org/wiki/Main_Page')
